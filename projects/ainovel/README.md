# AI Novel Project

이 폴더는 `ainovel` 브랜치에서 새로 진행하는 별도 공모전용 현대판타지 프로젝트다.

## 작업 범위

- 이 프로젝트 작업은 `projects/ainovel/` 내부에서만 진행한다.
- 기존 demonking 프로젝트의 루트 `episode/`, `design/`, `_workspace/`, `revision/`은 참조만 하고 수정하지 않는다.

## 현재 산출물

- `novel-config.md`: 새 프로젝트 설정
- `_workspace/00_contest_brief.md`: 공모전 기준 요약
- `_workspace/00_research/`: 하네스식 R1/R2/R5 초안
- `_workspace/01_proposals.md`: 3개 기획안 비교
- `_workspace/00_seed_ai_shaman_logs.md`: 추천작 시드
- `_workspace/02_synopsis_150eps.md`: 150화 간단 시놉스
