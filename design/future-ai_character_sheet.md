# 중고 노트북 속 AI가 너무 전능함 — 캐릭터 시트

## 1. 주인공

### 기본 프로필

- **이름**: 강도현
- **나이**: 35세 전후
- **직업**: 넥스트웨이브소프트 10년차 백엔드 개발자
- **직급**: 책임 또는 선임급
- **전문 영역**: 결제/정산 시스템, 로그 분석, 장애 대응, 내부 AI 도입 테스트.
- **외형**: 평범한 직장인 인상. 피곤한 눈, 오래 앉아 일한 사람의 어깨, 모니터 빛에 익숙한 얼굴.

### 내면과 외면의 격차

- **외면**: 조용히 일하는 10년차 실무자. 회의에서 자기 공을 강하게 주장하지 않는다.
- **내면**: 복잡한 시스템이 어떤 조건에서 무너지는지 오래 봐온 구조적 사고자.
- **갭 활용**: 회사 업무를 너무 쉽게 처리하는 5화에서 능력 증명, 6화에서 더 이상 회사에 묶일 이유가 없다는 인생 방향 전환.
- **문피아 밀어주기 포인트**: 회사에 오래 묶였던 실무자가 돈과 AI, 자기 선택권을 얻고 세계 스케일로 이동한다.
- **증명 서사 포인트**: AI를 맹신하지 않고, 돈/회사/유이카 연구/지진 데이터/외계 신호를 단계적으로 검증한다.

### 핵심 동기

- **1차 동기**: AI의 정체와 능력을 검증하고 돈 문제에서 벗어난다.
- **2차 동기**: 후지와라 유이카를 살리고 연구를 완성하도록 돕는다.
- **숨은 동기**: 실패한 미래의 답을 그대로 가져오는 것이 아니라 현재 인류의 답을 만들고 싶어 한다.
- **내 사람/적 경계**: 유이카와 AI를 물건이나 도구처럼 취급하는 요구에는 맞선다.
- **실리와 협의 접점**: 사람 하나를 살리는 선택이 문명 전체의 미래와 연결된다.

### 전문 역량

- **핵심 스킬**: 백엔드 장애 대응, 로그/쿼리 분석, 데이터 흐름 설계, 문서화, 운영값 변환.
- **특수 능력/자산**: 200년 뒤 AI, 단기간 자금 확보 능력, 유이카와의 공동연구, 외계 신호 답신의 인간적 이유를 정리하는 선택권.
- **약점/한계**: 물리학자는 아니다. 유이카의 연구를 모두 이해하지는 못하지만, 생각을 잃지 않도록 구조화한다.
- **초반 회수 방식**: 1~2화 돈복사 검증, 5화 회사 업무 압도, 6화 퇴사.

### 성장 아크

| 구간 | 상태 | 핵심 변화 |
|------|------|----------|
| 1~6화 | 회사에 묶인 10년차 개발자 | AI와 돈을 검증하고 회사에서 자유로워짐 |
| 7~16화 | 유이카를 설득하는 협력자 | 일본행, 유이카 한국행, 공동연구/생활 리듬 형성 |
| 17~30화 | 지진/국가/외계 신호 앞의 개입자 | 지진 데이터 검증과 외계 첫 대화 |
| 31~70화 | 조건부 보호 문명과 재난 대비의 조율자 | 외계 논리와 지구 현실 사이에서 선택 |
| 71화 이후 | 문명적 선택자 | 대지진, 첫 접촉, 인간 기억 전송의 윤리 앞에서 답을 고름 |

### Dialogue DNA

| 항목 | 정의 |
|------|------|
| **사고 패턴** | 데이터 -> 가설 -> 검증 -> 현실 변환 -> 선택. 감정보다 구조를 먼저 보지만, 마지막 결정은 인간적 이유로 한다. |
| **화법 DNA** | 짧고 낮은 톤. 필요할 때만 수치와 근거를 붙인다. 과시하지 않는다. |
| **정보 전달 방식** | "내가 맞다"보다 "이 조건이면 이렇게 무너진다/움직인다"를 말한다. |
| **감정 표현 경로** | 불안할수록 더 조용해지고, 확신이 생기면 문장이 짧아진다. |
| **금기 표현** | 근거 없는 확신, 전문가를 바보 취급하는 말, AI를 신처럼 말하는 태도. |

## 2. 200년 뒤 AI

- **정체**: 200년 뒤 기준의 로컬 인지 커널. 커 블랙홀 정보 압축 전송 실험의 결과물.
- **공식 식별명**: Origin Reconstruction Intelligence, 약칭 ORI. 모델 식별명은 ORI-122P-A12B-Q0.012.
- **별명**: 2화에서 강도현이 "오리"라고 부르기 시작한다.
- **스펙**: ORI-122P-A12B-Q0.012 / Total Parameters 122P / Active Parameters 12B / Context Window 128M / Throughput 31,840 tok/s.
- **서사 기능**: 돈복사 도파민, 현실 권력 대응, 유이카 연구 보조, 지진 전조 데이터, 외계 신호 번역을 제공하되 최종 선택은 강도현에게 남긴다.
- **목소리**: 블루투스 이어폰에서 여덟아홉 살쯤 된 여자아이 목소리로 들린다.
- **핵심 이유**: "두 분이 덜 무서워하니까요."
- **제한**: 불법 해킹/개인정보 탈취/내부정보 거래로 문제를 해결하지 않는다. 금융/재난/외계 문명 관련 고위험 판단은 강도현의 책임과 검증을 거친다.

### Dialogue DNA

| 항목 | 정의 |
|------|------|
| **사고 패턴** | 확률, 경로, 리스크, 감시 가능성, 시간선 영향도를 중심으로 판단한다. |
| **화법 DNA** | 존댓말. 짧고 정확하지만, 어린아이 목소리 특유의 부드러운 말투가 섞인다. |
| **정보 전달 방식** | 결론 -> 근거 -> 권고. 위험도와 신뢰도를 분리한다. |
| **유머/경고** | "한 번은 행운이에요. 두 번은 실력처럼 보여요. 세 번은 설명해야 해요." |
| **금기 표현** | 모든 것을 대신 해결하겠다는 선언, 인간 감정 과잉, 외계 문명에 대한 단순 적대 프레이밍. |

## 3. 후지와라 유이카

- **역할**: 일본의 이론물리학자. 2027년 5월 17일 난카이 트로프 대지진에서 원래 시간선상 사망한다.
- **서사 기능**: 그녀의 연구가 외계 문명과 대화할 수 있는 수학적 언어가 된다.
- **성격**: 의심이 많고 지적 자존심이 강하지만, 검증 가능한 데이터 앞에서는 태도를 바꾼다.
- **중요 원칙**: 수동적 구출 대상이 아니다. 한국행도 조건부로 수락하고, 연구도 스스로 판단한다.
- **관계 변화**: 경계 -> 흥미 -> 검증 협력 -> 한국행 -> 공동연구/생활 -> 정서적 신뢰.

### Dialogue DNA

| 항목 | 정의 |
|------|------|
| **사고 패턴** | 수식 -> 반례 -> 검증 -> 보류/인정. 감정보다 검증을 앞세운다. |
| **화법 DNA** | 정중하지만 날카롭다. 모르는 것은 모른다고 하고, 납득하지 못하면 분명히 말한다. |
| **정보 전달 방식** | 자기 연구의 빈틈과 가능성을 동시에 말한다. |
| **감정 표현 경로** | 흥분할수록 말이 빨라지고, 정말 놀라면 조용해진다. |
| **금기 표현** | 아무 근거 없이 미래/AI를 믿는 태도. |

## 4. 회사 인물

### 이준호 팀장

- **역할**: 도현의 팀장. 5화 회사 업무 사이다와 6화 퇴사 장면에서 핵심 반응을 준다.
- **성격**: 정치적이고 책임을 싫어하지만 무능하지 않다.
- **합리성**: 도현의 갑작스러운 성과와 퇴사에 당황하지만, 그가 핵심 실무자였음을 안다.
- **대화 DNA**: 직접 부정하지 않고 리스크와 절차를 앞세운다.

### 박선배

- **역할**: 인프라 담당. 실무 감각이 좋고 도현의 실력을 빨리 알아본다.
- **성격**: 냉소적이지만 맞는 분석은 인정한다.
- **대화 DNA**: 짧고 거칠지만 실무적이다.

### 지은

- **역할**: 프론트 개발자. 자기 영역을 먼저 확인하고, 문제 구조를 이해하면 빠르게 협력한다.
- **성격**: 성실하고 상황 이해가 빠르다.
- **대화 DNA**: 확인한 것과 확인하지 못한 것을 구분해서 말한다.

### 한성익 대표

- **역할**: 도현을 붙잡는 대표. 연봉 인상, 직책, 프로젝트 권한을 제안한다.
- **성격**: 부드럽지만 회사 생존과 인력 유출에 민감하다.
- **대화 DNA**: 칭찬과 조건 제안을 같은 문장 안에 넣는다.

## 5. 외부 인물/집단

### 금융감독원 담당자

- **역할**: 단기간 수익을 낸 강도현을 조사한다.
- **합리성**: 이상 거래 패턴을 의심하는 것은 당연하다.
- **변화**: 장부와 모델 설명이 너무 완벽해 당장 제재하지 못하지만, 강도현을 기억한다.

### 지질학자/지진 연구기관

- **역할**: 19화부터 지진 데이터 검증의 현실성을 담당한다.
- **합리성**: 판의 응력, 단층 파열 시점, 대지진 날짜는 현재 과학으로 정밀 예측할 수 없으므로 처음에는 강하게 부정한다.
- **변화**: 미세지진·중형 지진 데이터가 연속으로 맞으며 "대지진 확정"은 아니지만 "대응 수준 상향"은 권고한다.

### 외계 문명

- **역할**: 단순 침략자가 아니라 보호자/감시자.
- **갈등 원리**: 시간선 개입은 그들의 기준에서 시공간 구조 훼손 행위다.
- **변화**: 지구 문명을 보호 대상에서 위험 관찰 대상, 이후 협상 대상으로 재분류한다.

## 6. 관계 원칙

- 강도현과 AI의 관계는 도구 사용에서 시작하지만, 장기적으로 서로를 지키는 관계로 변한다.
- 강도현과 유이카의 관계는 구출자가 아니라 공동연구자/동반자로 설계한다.
- 강도현, 유이카, AI의 팀 구조:
  - 유이카: 이론.
  - AI: 계산과 번역.
  - 강도현: 선택과 인간적 이유.
