# 중고 노트북 속 오리가 너무 전능함 — 플롯 및 훅 가이드

이 문서는 전체 플롯 구조의 빠른 참조다. 세부 비트는 `design/future-ai_synopsis_ep001-030.md`와 `design/future-ai_long_arc_after_ep030.md`를 우선한다.

## 1. 대주제 서사선

- 테마: 돈과 AI를 얻은 개인이, 한 사람을 살리려는 선택을 통해 인류 대표성에 가까운 선택자로 확장된다.
- 메인 퀘스트: 오리와 함께 후지와라 유이카를 살리고, 그녀의 연구를 완성시켜 외부 관측자와 대화할 수 있는 수학적 언어를 마련한다.
- 서사 공식: 현실 문제 -> 오리 분석 -> 강도현의 검증/선택 -> 합리적 반대 -> 실행 -> 사이다/보상 -> 더 큰 질문.

## 2. 초반 회차 리듬

- 1화: 중고 노트북, 오리 등장, 돈복사 제안.
- 2화: 3분 17초 검증, 5천만 원 수익, 사용자 등록, 돈이 목적이 아니라는 훅.
- 3화: 회사 출근. 정산 오류 회의와 배포 전 장애 차단으로 업무 사이다. 퇴사는 충동만 생기고 보류.
- 4화: 후지와라 유이카, 난카이 트로프, 생존 목표, 파트너 등록. 회사를 떠나야 할 이유 확보.
- 5화: 퇴사. 팀장, 상무, 민수와의 정리로 유이카에게 향할 준비 완료.
- 6화: 유이카 논문, 메일, 화상 통화, 공개 세미나 초대.
- 7화: 일본행 준비, 오리 전능감, 노란 오리 키링, 교토 도착.
- 8화: 공개 세미나, 유이카의 물리적 인상 각인, 첫 대면 직전.
- 9화: 첫 대면과 질문 검증 시작.

초반에는 외계 간섭전, 시간선, 외부 관측자 설명을 길게 풀지 않는다. 독자가 먼저 체감해야 할 것은 오리의 압도적 능력, 도현의 검증력, 회사 사이다, 유이카를 살려야 하는 목적이다.

## 3. 1~30화 아크 구조

| 구간 | 핵심 | 보상 | 다음 압박 |
|------|------|------|----------|
| 1~2화 | AI 획득과 돈 검증 | 돈 문제 해소, 오리 호칭 정착 | 돈이 목적이 아님 |
| 3~5화 | 회사 업무 사이다, 유이카 목적 공개, 퇴사 | 인정, 이유, 자유, 인수인계 | 유이카 접촉 |
| 6~8화 | 유이카 접촉과 일본행 | 메일/통화 성공, 세미나 초대 | 직접 검증 |
| 9~15화 | 유이카/츠무기 설득과 한국행 | 연구 협력, 인간적 이유 | 현실 절차와 안전 |
| 16~22화 | 오리 물리적 한계 보완, 데이터 공개, 난카이 대응 | 재난 피해 감소, 유이카 생존 | 국가 단위 관심 |
| 23~30화 | 일본 감사, 국가 의심, 미국/중국/북한 대응 | 귀빈이자 위험인자 | 외부 관측자 반응 재개 |

## 3-1. 31~45화 아크 구조

| 구간 | 핵심 | 보상 | 다음 압박 |
|------|------|------|----------|
| 31~34화 | 귀빈 생활, 연구지원, 외부 반응, 보호 수단 | 국가 지원과 연구 진전, 유이카와 도현 거리 축소 | 외부 관측자의 조건 반응 |
| 35~37화 | 미래 기억 전이 흔적, 네이튼의 그림자, 네이튼 등장 | 더 큰 적/생존자 공개, 미래 실패의 감정 유입 | 오리의 미래 권한 구조 흔들림 |
| 38~40화 | 도구와 동료, 첫 충돌, 연구 데이터 탈취 | 오리 자율성 강화, 도현의 보호자 태도, 유이카 반말 첫 의지 | 외부 관측자 직접 반응 |
| 41~43화 | 외부 관측자의 판정, 네이튼 추적, 시간선 배제 | 도현이 외부 관측자 명령을 그대로 따르지 않음 | 외부 관측자의 보호/관리 논리 의심 |
| 44~45화 | 후폭풍, 오리 노트북 앵커 | 오리의 존재성 확정, 노트북이 생명선이 됨 | 미확인 문명 응답 |

| 6화 | 논문 분석/질문 생성 | 메일과 화상 통화 | 천재 과학자 접촉 |

| 35~37화 | 미래 기억 전이 신호 | 네이튼 흔적과 직접 등장 | 새 적/생존자 공개 |
| 38~43화 | 오리 권한/유이카 연구 데이터 | 네이튼 충돌과 외부 관측자 판정 | 오리 자율성 |
| 44~45화 | 노트북 앵커 | 오리 생명선과 미확인 문명 응답 | 장기 갈등 진입 |

## 5. 금지 플롯 패턴

- 유이카를 수동적 구출 대상만으로 쓰지 않는다.
- 오리를 불법 해킹, 개인정보 탈취, 내부정보 거래 버튼으로 쓰지 않는다.
- 회사, 고객사, 국가, 전문가를 멍청하게 만들지 않는다.
- 외부 관측자를 단순 침략자나 악당으로만 쓰지 않는다.
- 난카이 트로프 대지진 날짜 예측은 과학계가 처음부터 공식 인정하지 않는다. 데이터가 누적된 뒤에도 "대응 수준 상향"이 현실적 언어다.
