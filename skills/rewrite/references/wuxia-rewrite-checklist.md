# 무협 리라이트 체크리스트

무협 에피소드를 재작성할 때 적용하는 장면 단위 수정 기준이다. 기존 플롯을 보존하되, 설명문을 장면으로 바꾸고 인물의 명분과 대가를 선명하게 만든다.

## 적용 시점

- rewrite 대상 작품이 무협/강호/무림/문파/무공/정파/사파/마교 장르일 때 적용한다.
- episode-rewriter는 이 파일과 `skills/create/references/wuxia-scene-style.md`를 함께 참조한다.
- quality-verifier는 재작성 검증 시 `skills/polish/references/wuxia-quality-checklist.md`의 PASS/REVISE 기준을 참조한다.

## 우선순위

1. 설정문서와 플롯 비트를 보존한다.
2. 기획서식 요약을 장면으로 전환한다.
3. 감정 판정을 행동, 감각, 침묵으로 바꾼다.
4. 주인공의 승리, 깨달음, 힘 사용에 대가를 남긴다.
5. 조연과 적의 정보, 욕망, 체면, 두려움을 복원한다.
6. 무공은 기술명보다 몸의 언어로 구현한다.
7. 장면 끝에는 변화나 다음 위험을 남긴다.

## 리라이트 변환 규칙

| 기존 문제 | 수정 방향 |
| --- | --- |
| 스승의 죽음 이후 복수를 결심했다 | 죽음의 방, 남겨진 물건, 챙기는 것과 두고 가는 것으로 결심을 보인다 |
| 적이 사악해서 공격했다 | 적의 명분, 손익, 체면, 정보 오해를 부여한다 |
| 주인공만 진실을 알아챘다 | 다른 인물도 단서를 잡게 하되, 주인공은 작은 모순 하나를 더 본다 |
| 검기가 폭발해 압도했다 | 발, 호흡, 손목, 검 끝, 피할 자리의 소멸로 전투를 쓴다 |
| 비통했다/분노했다 | 손, 호흡, 식은 음식, 이름을 부르다 멈추는 행동으로 바꾼다 |
| 승리로 사건이 끝났다 | 명분 손실, 더 큰 배후, 몸의 손상, 관계 균열 중 하나를 추가한다 |

## 장면 보존

전체 재작성보다 장면별 수술을 우선한다.

- 장면의 목적이 살아 있으면 문체와 행동만 고친다.
- 장면의 변화가 없으면 끝에 선택, 발견, 침묵, 상실, 다음 위험 중 하나를 추가한다.
- 설정 설명 문단은 가능한 한 대화의 압박, 물건, 장소의 흔적, 인물의 회피 행동으로 분산한다.
- 인물의 진심을 직접 밝힌 문장은 행동 근거만 남기고 삭제한다.

## 무협 카타르시스 복원

재작성 후 다음 중 하나 이상이 선명해야 한다:

- 한: 끝내 삼킨 말, 버리지 못한 물건, 늦은 반응.
- 정: 반복된 행동으로 생긴 빚과 약점.
- 협: 계산상 손해인 선택과 그 대가.
- 강함: 파괴 규모가 아니라 상대의 선택지가 사라지는 감각.
- 지능: 말하지 않는 것, 먼저 확인하는 것, 숨기는 정보.
- 강호: 돈, 약재, 제자, 체면, 정보망, 관아의 논리.

## 재작성 완료 체크

- 감정명이 줄고 물리적 행동이 늘었는가?
- 장면마다 끝의 변화가 있는가?
- 주인공의 힘 사용에 대가가 남았는가?
- 적과 조연이 자기 명분으로 움직이는가?
- 무공 장면이 기술명 요약이 아니라 몸의 언어로 보이는가?
- 대사가 정보 전달보다 목적 수행을 하는가?
- 마지막 문장이 해설이 아니라 대사, 행동, 이미지 중 하나인가?
