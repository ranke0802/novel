# 에피소드 평가 루브릭

## 평가 목적

5화 단위 집필 후 제3 평가자가 각 화의 재미도와 다음화 클릭 욕구를 수치화한다. 가장 중요한 항목은 절단마공이다.

## 항목별 점수

각 항목은 10점 만점이다.

| 항목 | 설명 | 가중치 |
|---|---|---|
| 절단마공 | 마지막 300~500자가 다음화를 누르게 만드는가 | 30% |
| 제목값 | "사실 마왕이 하려던 건 이게 아니었는데"의 아이러니가 살아 있는가 | 15% |
| 유리카 내면 재미 | 가르바의 오만/굴욕/계산/흔들림이 재미있는가 | 15% |
| 아이 몸 제약 | 7세 몸, 아이 행세, 배고픔, 습관 연기가 서사에 쓰였는가 | 10% |
| 오두막 디펜스 | 사냥꾼 아버지, 함정, 결계, 마석, 위협이 작동하는가 | 10% |
| 칼 마리하 떡밥 | 감시/성역핵/기억/인연 위협이 과하지 않게 들어갔는가 | 10% |
| 톤 일관성 | 코미디와 불길함의 균형, 문체 안정성 | 5% |
| 과설명 억제 | 설정 설명보다 장면으로 보여주는가 | 5% |

## 종합 점수

종합 = 절단마공*0.30 + 제목값*0.15 + 유리카내면*0.15 + 아이몸*0.10 + 디펜스*0.10 + 마리하떡밥*0.10 + 톤*0.05 + 과설명*0.05

## 재작성 기준

- 종합 7.5 미만: 해당 화 보강.
- 절단마공 8 미만: 마지막 장면 재작성.
- 유리카 내면 재미 7 미만: 독백과 체면 붕괴 보강.
- 과설명 6 이하: 설명을 장면/행동으로 치환.
