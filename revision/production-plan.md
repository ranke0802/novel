# 150화 제작 계획

## 전체 원칙

- 150화 완결.
- EP001은 정본 본문으로 고정하고 수정하지 않는다.
- 5화 단위로 집필, 평가, 보강을 반복한다.
- 각 화의 기본 흐름은 생활 사건으로 가볍게 열고, 이름/인연/성역의 진중한 장면을 짧게 꽂는다.
- 아버지 이름은 끝까지 비공개로 유지한다.
- 유리카/가르바가 주인공이다. 가르바는 스스로를 `마왕`이라 칭하지 않는다.
- 의탁은 흡수가 아니다. 유리카가 품은 인연은 원래 자리로 돌려보내야 한다.

## 5화 단위 파이프라인

1. 해당 5화의 세부 플롯 확인.
2. 직전 2화와 EP001 문체 기준 확인.
3. episode/epNNN.md 작성.
4. revision/evaluation_EPXXX-EPYYY.md 생성.
5. 1화 문체 이탈, 과설명, 유리카 수동화, 의탁/수확 혼동이 있으면 보강.
6. revision/batch-status.md 갱신.

## 150화 아크

- EP001~EP015: 성공한 죽음, 실패한 귀환.
- EP016~EP030: 의탁되는 인연.
- EP031~EP045: 배신한 왕.
- EP046~EP060: 성역의 도시.
- EP061~EP075: 성검은 누구의 것인가.
- EP076~EP090: 이름을 되돌리는 아이.
- EP091~EP105: 성역핵의 도시.
- EP106~EP120: 관조하는 자비.
- EP121~EP135: 복권되는 섭리.
- EP136~EP150: 경험치를 잃는 여신.

## 중후반 필수 인물축

- 아버지와 유리카의 정체 수용.
- 성녀의 믿음 붕괴와 재선택.
- 생존 상급 마물 조연의 불완전한 협력.
