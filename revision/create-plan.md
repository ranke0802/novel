# 에피소드 창작 계획

## 대상: EP001~EP050

- EP001은 정본 본문. 수정 금지.
- EP002~EP006은 현재 재미가 살아난 기준 본문.
- EP007~EP050은 새 1부 성장 사다리에 맞춰 다시 작성 완료.
- 기존 EP007~EP050 본문은 폐기된 세계선으로 간주한다.

## 현재 고정 본문

- [x] EP001 — 성공이군. 신살 일부 성공, 마하칼리의 반격, 유리카 탄생.
- [x] EP002 — 성검은 사람을 잘못 고른다. 0~7세 압축, 가르바 자아 회복, 성검 이상 반응.
- [x] EP003 — 튜토리얼은 학살이었다. 첫 마물 학살과 인연 조각 회수.
- [x] EP004 — 하찮은 마법. 생활 마법의 실용성 확인.
- [x] EP005 — 신규 용사 등록. 성검의 사용자 확정과 성역 종소리.
- [x] EP006 — 용사 교육은 사양이다. 아버지의 직접 훈련 선언과 성역 사절 도착.

## EP007~EP050 신규 작성 계획

- [x] EP007~EP010 — 성역 확보전. 교육 인계 거부, 성검 앞 거짓말, 아버지의 첫 수업, 첫 합동전.
- [x] EP011~EP015 — 첫 사냥 루프. 추적, 함정, 하급 마물 조각 회수, 왕좌 반응, `배신자` 훅.
- [x] EP016~EP020 — 인간도 먹힌다. 마을, 감사 회수, 포식 유혹, 내면 유리카의 브레이크, 아버지의 침묵.
- [x] EP021~EP025 — 의탁의 대가. 비살상 절단, 살아남은 마물, 기록자의 덫, 조각을 품는 그릇, `포식 징후`.
- [x] EP026~EP030 — 성검 운용. 사슬과 실의 구분, 아버지의 그림자, 공개 시험, 말하지 않는 해명, 숲이 무릎 꿇는 밤.
- [x] EP031~EP035 — 첫 상급 마물. 배신자 오해, `나는 먹지 않았다`, 바이라바 이름 언급, 첫 사슬 절단 실패, 생존 훈련.
- [x] EP036~EP040 — 옛 전장. 아버지의 죄, 바이라바의 팔 잔향, 첫 번째 증인, 세 번 죽지 않는 법.
- [x] EP041~EP045 — 바이라바전 예비 증명. 포식자로 몰림, 태우면 이기는 유혹, 아버지의 확신, 각자의 얼굴, 바이라바 수육체 예고.
- [x] EP046~EP050 — 마하칼리의 수육체 바이라바. 첫 패배, 포식 거부, 증인들, 흰 사슬 절단, 가장 강한 수족 귀환.

## 작성 원칙

- EP001은 절대 수정하지 않는다.
- 매 화 마지막은 절단마공으로 닫는다.
- 7~50화의 모든 성장은 EP050 바이라바전에서 쓰여야 한다.
- 성장은 힘 상승만이 아니라 `먹지 않고 짊어지는 법`의 증명이어야 한다.
- 유리카가 강해질수록 아버지는 자랑보다 먼저 두려움과 마야의 부재를 느낀다.
- 유머는 성검 오작동, 용사 교육 거부, 아버지의 팔불출 훈련, 하찮은 생활 마법의 실전성에서 뽑는다.
